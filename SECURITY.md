# Security policy

## Supported version

Security fixes are applied to the current version on the `main` branch and the live deployment.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Email
[ucaisoc@outlook.com](mailto:ucaisoc@outlook.com) with:

- the affected page or endpoint;
- clear reproduction steps;
- the impact you observed; and
- any suggested remediation.

We will acknowledge the report as soon as the volunteer committee can and coordinate disclosure
after a fix is available.
